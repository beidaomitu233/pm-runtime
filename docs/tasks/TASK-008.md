# TASK-008 导出已保存版本

对应 R08；来源 §3.2、§9、§14、A09。依赖 TASK-007。

目标：用户将生成或人工编辑后的指定版本导出为 drawio/SVG/PNG，内容一致且可外部使用。

入口：Diagrams → 选择当前或历史版 → 导出格式 → 本机保存框 → 完成。存在未保存修改时先保存或取消，不导出过期内容。取消保存框不报错、不写文件。

修改范围：features/diagrams/export、desktop/main 文件写入与导出桥、编辑器消息关联。无需新增数据库表、服务端云转换或 MCP 工具。drawio 复制已存 XML，SVG/PNG 使用同一已保存版本在本地编辑器转换。

约定：导出进行中锁定目标 revision；single flight，迟到响应拒绝。校验 data URI、MIME、SVG 外部引用、PNG 签名和像素/字节限制；等待中文字体就绪，输出背景/裁切按固定默认值记录。外部目标路径仅来自用户文件对话框。

异常：中文字体缺失、编辑器超时、响应属于另一图、用户取消、目标文件被占用、磁盘满、超大图。失败保留源版本并允许重试，不新增 revision；不切到在线导出服务。

验收：流程图、两种方向泳道、人工修改版各导出三格式；drawio 在独立 draw.io 可继续编辑；SVG 在浏览器打开、PNG 在图像查看器打开，100% 中文无缺字、内容不裁切。断网重复以上导出。`npm test -- export` 覆盖错响应和格式/大小边界，人工记录文件、版本与截图，不能仅断言文件存在。

# TASK-012 恢复、诊断、Windows 打包与发布验收

状态：待开发  
依赖：TASK-003～TASK-011  
对应验收：A01-A10、Q01-Q02  
业务目标：把已经逐项验收的功能收口成可安装、可恢复、可诊断的 Windows x64 v0.1 发布候选，并执行全量业务回归。

实现启动恢复：检查 WAL、pending/importing/rendering 状态、临时目录和孤儿文件，恢复操作必须幂等且不得误删正式文件。完善 Diagnostics，数据库不可用时仍返回最小版本/状态，所有信息去敏。实现日志滚动、保留和隐私扫描。完成 Tauri + self-contained sidecar Windows x64 打包，目标机器无需 Node.js 或开发依赖。

验收环境至少包含一台干净 Windows x64、无 Node.js 的测试机。输出 release candidate 版本、安装/卸载/重启结果、所有测试命令、人工评分、已知限制和剩余问题。只有 P0/P1 发布阻塞清零且 A01-A10 有证据时，项目经理才能标记 v0.1 阶段完成。
